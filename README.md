# 苹果翻转棋

在线对弈：https://penzai-py.github.io/apple-othello/

一个从零自对弈训练出的翻转棋 AI。翻转棋规则和一个 161 万参数的 KataGo 式卷积网络（带全局池化）都用
JavaScript 在浏览器里运行，不需要服务器。`index.html` 是页面，`weights-<hash>-NN.bin` 是切成 256 KB 小块的 fp16 网络权重（分块下载，某一块卡住只重试那一块）。

AI 在网络之上做 alpha-beta 搜索，默认 3 层（可选 1 / 2 / 3 层；1 层就是直接选网络估计胜率最高的落点），
搜索在 Web Worker 里跑，不会卡住页面。页面同时显示：

- 胜率条：AI 对当前局面黑白双方胜率的估计；
- 终局归属：每格上一个小方块，黑 / 白表示网络判断这一格终局归谁，越不透明越确定，可以关闭；
- 预计终局子差：64 格归属判断的求和。

默认 3 层时对固定策略的成绩：对 4 层 alpha-beta 搜索 98.1%，对 2 层 99.5%，对"每步翻子最多"策略 98.7%，对随机落子 99.8%。
